# Между нами · интерактивный 3D-прототип

Новая версия находится только в `mobile-next`. Основной проект, сервер и ранний `next-app` сохранены.

## Запуск на этом Windows-ПК

Открыть `http://localhost:8081`, пока работает сервер. Для самостоятельного запуска дважды нажать **Start-BetweenUs.cmd** в этой папке. Окно сервера оставить открытым.

Либо в терминале:

```powershell
cd mobile-next
npm.cmd ci
npm.cmd run export:web
npm.cmd run preview
```

Затем открыть http://localhost:8081. Сборка и зависимости уже созданы на ПК; повторная установка нужна только после получения проекта заново. Если порт занят предыдущим сервером, используйте его либо закройте его окно.

Для разработки: `npm.cmd run web`. Для будущей проверки на телефоне: `npm.cmd start` и совместимый с SDK 54 клиент/development build. Нативный запуск на телефоне пока не подтверждён. APK/IPA в этом этапе не выпускались.

## Что попробовать

1. Нажать на Ростика или Искру: круговое меню с различными действиями.
2. Нажать на диван, лампу, стол или картину. Кнопка палитры справа открывает редактор.
3. В редакторе выбрать тему; нажать диван для цвета, формы и поверхности, картину — для встроенного каталога. Undo/redo меняют черновик; «Сохранить» фиксирует его, крестик отменяет.
4. Отправить сообщение в «Общении» и вернуться в комнату. Сердечко в комнате тоже добавляет запись в чат.
5. В «Активностях» выбрать «Задачи», добавить дело, завершить его и нажать «Сохранить как воспоминание». Оно появится в «Истории» со связью на исходную запись.
6. В «Ещё» нарисовать один замкнутый силуэт и нажать «Оживить силуэт». Исходный контур сохранится, Ростик примет его объёмную форму.
7. Перезагрузить страницу: чат, записи, оформление и рисунок остаются в этом браузере.

## Проверки

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run export:all
# Сервер preview должен работать в другом окне.
$env:CHROMIUM_PATH='C:\Program Files\Google\Chrome\Application\chrome.exe'
npm.cmd run test:browser
```

`CHROMIUM_PATH` необязателен при установленном Playwright Chromium (`npx playwright install chromium`). Browser-check создаёт отдельный временный профиль и не использует личные данные вашего браузера. Результаты и реальные снимки рендера сохраняются в `screenshots/`.

## Границы прототипа

Рендеринг — настоящее 3D (Three.js/WebGL и Expo GL). Персонажи и анимации процедурные. Редактор рисунка — простое выдавливание контура, без полноценного скелета и отдельного размещения деталей. Все данные локальные, AsyncStorage не является зашифрованной production-БД. Нет доставки сообщений, сервера присутствия, реальной связи двух пользователей, ИИ и покупок. Обложки воспоминаний декоративные. Демо-имена и первые записи можно отличить по описаниям.

Аудит, выбор архитектуры и следующие задачи: [docs/AUDIT-2026-10-22.md](docs/AUDIT-2026-10-22.md).
