## Карта
- Общение: обзор → единая переписка, реакции/ответы/закрепления, знаки внимания, настроение, вопросы, поддержка, договорённости, личный/общий помощник и посредник.
- Активности: неделя → повестка → планы/дела/идеи → календарь (месяц/неделя/день), задачи (список/доска/календарь), идеи, голосования, цели, привычки, бюджет, адаптивная карточка, универсальное создание.
- Мир: личная/общая комнаты, вертикальный жест и доступная кнопка, масштаб +/- (комната → дом → город → глобус), разные радиальные действия, интерьер, персонаж, единый быстрый чат.
- История: сезонная дорога и список, поиск, библиотека, альбомы, дневники, письма, капсулы, книга, блочный редактор, версии.
- Ещё: профиль/связи, оформление, кошельки/магазин, заметки, приватность, устройства, подписка/ИИ, уведомления/виджеты, хранение/экспорт, помощь.
- Сквозные: поиск, согласования, доступ, локальное сохранение, состояния загрузки/ошибки.

## Границы
Expo + React Native + TypeScript. SDK 54 выбран для простого тестирования через доступный в App Store Expo Go; версии native-пакетов определяет expo install. Компоненты UI отдельно от предметной модели и репозитория. AsyncStorage — адаптер демонстрационного локального хранилища, не зашифрованная production-БД. Не вводить реальные секреты.

User, Space, Record, Message, Media, ChangeRequest — разные сущности; связи по ID. Записи специализированы типом, связанные планы не копируют медиа. Репозиторий сериализует записи и хранит схему версии. Серверный транспорт отсутствует; локальные сообщения имеют статус «На устройстве», никогда «Доставлено». Только собственные голоса/ответы меняются локально.

2.5D-комната — собственная векторная сцена с интерактивными объектами и анимацией. Это промежуточный renderer, не полноценный 3D. Пространственные уровни — честно обозначенный концептуальный просмотр. Дорога использует обычные записи и сезонную графику, без реконструкций событий.

Следующий инфраструктурный этап: authenticated transport, серверные ACL, шифрование/отзыв кеша, идемпотентная очередь операций, CRDT по блокам с сохранением обеих конфликтных версий, проверка финансовых операций на сервере. Реальная доставка, live presence, платежи, ИИ и push не симулируются как работающие.
