# Между нами — отдельный визуальный MVP

**Это новая версия, изолированная в `next-app/`. Старое приложение Expo 0.3.0 не изменено.**

## Запуск
Требуется Node.js и npm, интернет для первой установки пакетов.

```bash
cd next-app
npm install
npx expo start
```

Откройте QR через Expo Go, если версия Expo Go совместима с Expo SDK проекта, либо запустите web/Android/iOS соответствующими командами. При несовместимости SDK понадобится development build.

## Что есть
- Пять вкладок: Общение / Активности / Мир / История / Ещё.
- Панель «Наша жизнь»: календарная неделя, выбор даты, планы, задачи, идеи.
- Демонстрационный чат с общим массивом сообщений, быстрым полем отправки и последним сообщением в облачке.
- Уровни мира с кнопками +/− и комнаты с переключением.
- Упрощённая иллюстративная дорога воспоминаний и карточки событий.
- Локальные сообщения, задачи, идеи и названия воспоминаний сохраняются в SQLite KV-хранилище между перезапусками приложения. Остальные экраны пока демонстрационные.

## Что пока не реализовано
Это **интерактивный прототип**, а не рабочая серверная версия: нет регистрации, реальной доставки сообщений, облачного хранения, 3D-рендера, прав и серверной офлайн-синхронизации. Локальные данные хранятся на конкретном устройстве, а не у партнёра. Очистка приложения удалит их.
