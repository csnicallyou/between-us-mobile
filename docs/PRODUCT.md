# Product

«Между нами» — не трекер партнёра и не автоматический судья конфликтов. Это защищённое общее пространство,
которое помогает паре сохранять важные события, планы, мысли и договорённости.

## Основные принципы

- согласие важнее автоматизации;
- помощь важнее контроля доступности;
- у общих изменений есть автор и журнал;
- личный канал не раскрывается партнёру;
- ИИ готовит предложение, но не меняет данные скрытно;
- каждый пользователь может экспортировать и удалить свои данные;
- мобильный интерфейс должен быть понятным без технических знаний.

## Первая аудитория

Закрытая альфа для Антона и Лизы. После проверки безопасности и пользовательских сценариев — приглашённые
пары через TestFlight, затем публичный продукт.
