# Architecture

## Решение

Приложение строится на Expo SDK 57 и React Native 0.86. Expo Router обеспечивает файловую навигацию,
а TypeScript — единые контракты для iOS и Android.

### Почему Expo

- одна кодовая база для iOS и Android;
- EAS Build позволяет получать iOS-сборки без локального Xcode;
- SecureStore использует Keychain на iOS и Keystore на Android;
- Continuous Native Generation позволяет добавлять нативные настройки без постоянного хранения папок
  `ios/` и `android/` в репозитории;
- приложение можно постепенно расширять нативными модулями.

## Слои

### Presentation

`src/app` содержит только маршруты и композицию экранов. Переиспользуемые элементы находятся в
`src/components`, дизайн-токены — в `src/theme`.

### Domain

`src/domain` не импортирует React Native. Здесь находятся идентификаторы участников, планы, дневник,
настроения и календарные элементы. Это позволит использовать те же типы в синхронизации и тестах.

### State

Первый инкремент использует `AppDataContext` и локальный seed. Это временная реализация. Перед появлением
офлайн-редактирования необходимы репозиторий данных, журнал операций и разрешение конфликтов.

### Services

`secureStorage.ts` хранит только сессию и ключевой материал. `apiClient.ts` задаёт общий сетевой контракт,
тайм-аут и нормализованные ошибки. Адрес API передаётся через `EXPO_PUBLIC_API_BASE_URL`; секреты там
хранить нельзя.

## Будущая синхронизация

```text
UI -> use cases -> local encrypted database -> sync queue -> mobile API
                                                   |
                                                   +-> conflict resolver
```

Мобильное приложение не должно напрямую использовать текущий зашифрованный JSON веб-версии. Новый API
должен поддерживать пространства пар, отдельных пользователей, устройства, ротацию ключей, отзыв доступа,
версионирование записей и зашифрованные вложения.

## Платформенные границы

- Общая бизнес-логика остаётся в TypeScript.
- Различия iOS/Android концентрируются в адаптерах и дизайн-токенах.
- Биометрия, виджеты, push-уведомления и защита экрана реализуются через платформенные сервисы.
- Любая функция сначала проверяется на iOS, затем проходит Android-проверку до объединения в стабильный релиз.
