МЕЖДУ НАМИ 0.3.0 — УСТАНОВКА ДЛЯ АНТОНА НА WINDOWS

В этом архиве находятся:
- BetweenUs-unsigned.ipa — приложение для iPhone;
- BetweenUs-unsigned.ipa.sha256 — контрольная сумма файла;
- эта инструкция.

Что понадобится

1. iPhone и кабель USB.
2. Windows-компьютер с установленными официальными iTunes и iCloud от Apple.
3. Sideloadly с официального сайта: https://sideloadly.io/
4. Apple ID. Для тестирования безопаснее использовать отдельный Apple ID без фотографий и платёжных данных.

Установка

1. Подключи iPhone к компьютеру по USB, разблокируй его и нажми «Доверять этому компьютеру».
2. Запусти Sideloadly и дождись появления iPhone в поле iDevice.
3. Перетащи BetweenUs-unsigned.ipa на окно Sideloadly.
4. Введи email своего Apple ID в поле Apple ID и нажми Start.
5. Пароль и код двухфакторной аутентификации вводи только в окно Sideloadly. Не отправляй их в переписку.
6. Дождись сообщения Done.
7. Если iPhone запретит запуск:
   - открой «Настройки» → «Основные» → «VPN и управление устройством»;
   - выбери профиль своего Apple ID и нажми «Доверять»;
   - затем открой «Настройки» → «Конфиденциальность и безопасность» → «Режим разработчика»;
   - включи его и подтверди перезагрузку.
8. Запусти приложение «Между нами».

Первый запуск

1. Нажми «Создать аккаунт».
2. Укажи имя Антон, свой email и новый пароль приложения длиной не менее 10 символов.
3. Выбери «Создать пару».
4. Название можно указать «Между нами».
5. Дата начала отношений: 2026-02-10.
6. После создания отправь Лизе ссылку, QR-код или 12-символьный код.
7. Не добавляй старые планы и записи вручную: после подключения Лизы будет выполнен единый импорт без дублей.

Обновления

JavaScript-обновления приложение получает автоматически через Expo OTA. Если обновятся нативные модули, понадобится новая IPA. Бесплатная подпись Apple обычно действует 7 дней, после чего эту же IPA нужно снова подписать через Sideloadly.
