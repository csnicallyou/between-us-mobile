# Сессия 13 августа 2026 — мобильный визуальный редизайн

## Что уже работает

- У Антона и Лизы есть отдельные аккаунты и общая пара; данные синхронизируются через API на VPS, а не через телефон Антона.
- Работают планы, календарь, дневник, памятные события, важное о нас, договорённости, архив разборов, настроения, общий чат, Тихий канал, фотографии и фоновая тема.
- Пара создаётся приглашением: QR-код, deep link или одноразовый код. Сессии хранятся в iOS Keychain / Android Keystore через SecureStore.
- Приложение сейчас запускается на подключённом iPhone как Expo development build с Fast Refresh: изменение TypeScript-кода отправляется на телефон без пересборки IPA.

## Как подключён iPhone для live-разработки

1. На Windows открыт проект `D:\between-us-mobile` в VS Code.
2. iPhone подключён по USB и доверяет компьютеру.
3. На телефоне установлена development build «Между нами», не Expo Go.
4. Запуск Metro: `npm run start:dev-client` (если скрипт отсутствует — `npx expo start --dev-client --localhost`).
5. Открыть приложение на телефоне и выбрать появившийся development server. После сохранения кода работает Fast Refresh.
6. Снимок физического телефона: `D:\tools\pymobiledevice3\capture-iphone.ps1`. Результаты: `D:\between-us-mobile-live\screenshots`.

Не публиковать OTA-обновление и не собирать IPA ради обычных TypeScript/стилевых изменений. Новая IPA требуется только после изменения нативных зависимостей, `app.json`, iOS entitlements или Expo config plugins.

## Незавершённое — начать с этого

1. Визуально сверить **каждый** экран с соответствующим HTML-макетом на реальном iPhone, без «примерно похоже».
2. Довести единый нижний dock: единая форма с аккуратным вырезом под шар; без отдельного цветного круга, белой внутренней рамки и серой пустой зоны под ним.
3. Довести шар: это должна быть одна маленькая объёмная линза с частицами, бликами и тенью, а не отдельная большая полупрозрачная плашка.
4. Довести scroll-анимацию: у карточек, которые уходят под dock, должен быть понятный morph/слияние с шаром; не должно быть пустого места, видимых обрезанных краёв или «пузырей сбоку». Включать только там, где элемент действительно пересекает область dock, и оставлять статичный вариант при Reduce Motion.
5. После visual sign-off пройти все пользовательские действия: создание/редактирование/удаление планов и записей, фото, даты, договорённости, память, конфликты, чат, Тихий канал, настройки, поиск, экспорт, auth/pairing.
6. Затем собрать две IPA и проверить их на iPhone Антона и iPhone Лизы. Не обещать виджеты и push на бесплатной sideload-подписи: они требуют отдельной проверки и, вероятно, платного Apple Developer account.

## Ограничения и безопасность

- VPS также обслуживает VPN. Трогать только ресурсы Between Us: `between-us-api`, `between-us-edge`, PostgreSQL и каталог приложения. VPN, xray/hysteria/x-ui, firewall и их порты не менять.
- Детали доступа и секреты только в `D:\claude\vpn\HANDOFF.md`; не копировать их в git, логи или чат.
- `docs/CLAUDE_HANDOFF.md` содержит полный исторический контекст: API, сервер, импорт, auth, ограничения виджетов и push.
