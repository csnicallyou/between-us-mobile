# Бесплатная установка на iPhone по USB

Этот способ предназначен только для личного тестирования приложения на iPhone. GitHub Actions собирает
неподписанный `BetweenUs-unsigned.ipa` на macOS. Подпись бесплатным Apple ID и установка выполняются позднее
на Windows-компьютере через сторонний инструмент для sideloading.

## Ограничения бесплатной подписи Apple

- Приложение работает семь дней, после чего его нужно подписать и установить повторно.
- На одном устройстве одновременно может быть не более трёх приложений с бесплатной подписью.
- Некоторые возможности Apple, включая push-уведомления и часть облачных сервисов, недоступны.
- Сборка не предназначена для App Store, TestFlight или передачи другим пользователям.

## Получение IPA

1. Откройте вкладку `Actions` в приватном репозитории GitHub.
2. Выберите workflow `Build unsigned iOS IPA`.
3. Нажмите `Run workflow` и дождитесь завершения задания `Build for USB sideloading`.
4. В разделе `Artifacts` скачайте архив `BetweenUs-unsigned-ios`.
5. Распакуйте архив. Внутри находятся IPA и файл с его SHA-256.

## Установка с Windows

1. Включите на iPhone режим разработчика: `Настройки` → `Конфиденциальность и безопасность` →
   `Режим разработчика`.
2. Подключите iPhone к компьютеру по USB и подтвердите доверие этому компьютеру.
3. Установите выбранный инструмент для sideloading, например Sideloadly или AltStore, только с официального сайта.
4. Для подписи желательно использовать отдельный Apple ID без личных писем, фотографий и платёжных данных.
5. Выберите `BetweenUs-unsigned.ipa`, подпишите его бесплатным Apple ID и установите на подключённый iPhone.
6. Если iOS запросит доверие профилю, откройте управление VPN и устройством в настройках и подтвердите профиль.

Apple ID, пароль и коды двухфакторной аутентификации не должны добавляться в GitHub Secrets или передаваться
в репозиторий. Они используются только локально выбранным инструментом подписи.
